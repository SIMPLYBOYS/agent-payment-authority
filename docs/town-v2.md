## 2 為什麼鏡頭要會動

現在整個城鎮剛好一個畫面（城鎮 64×48 格，鏡頭框 41×34 格）。旅館與加油站各 17 格寬，加進去城鎮大約變成**兩個畫面寬**。若硬塞進一個畫面，每格會縮到 32 像素以下，像素會糊。所以：

- **鏡頭左右平移**：跟著正在發生的事走，例如客人走向某間店、進店、付款；沒有事時停在全城的某一段。
- **序幕的空景**：鏡頭從城西慢慢平移到城東，正好當影片開場。
- 遊戲模式：鏡頭跟著被操作的客人（現在的已知限制「鏡頭不跟著人」一併解決）。

- **三間店不動位置**，留在第一個畫面：現有的房間、門口、路線、測試都沿用。
- **旅館、加油站先當街景**（不能進去）；有路人進出、加油站有車在加油。
- **街道照截圖重排**：
  - 人行道加寬，靠車道一側有**路緣**；路樹改種在人行道的**方形樹穴**裡，和路燈、長椅、護柱等距排列。
  - 車道兩側有**停車格**（P）與**公車道**（BUS 字樣、公車亭）。
  - 東段加一條南北向的路，形成**十字路口**；每個路口有斑馬線與號誌。
  - 路面：中線虛線、人孔蓋；街角有**看板島**。

## 4 對現有功能的影響

| 項目 | 影響 |
|---|---|
| 三間店、房間、交易流程 | 不變 |
| 遊戲模式的步道（`walk`）與尋路 | 步道擴大到新街道；尋路沿用 |
| 路人、車流、號誌 | 路線重排，車流延伸到新路段；十字路口多一組號誌 |
| 展示視窗與主持人頁 | 城鎮階段的鏡頭由 Unity 平移；頁面不用改 |
| 測試 | LayoutTests、TownTests 要跟著新版面更新（步道、門口、遮擋、號誌） |
| 影片 | 序幕可以用鏡頭平移的空景；錄影延後到城鎮完成 |
